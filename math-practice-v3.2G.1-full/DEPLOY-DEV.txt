V3.2D.1 DEPLOYMENT

UPGRADE FROM V3.2D
1. Keep the deployed config.js and images/ folder.
2. Replace only index.html with the V3.2D.1 index.html.
3. Redeploy to the same site and hard refresh.
4. Confirm the page shows Version 3.2D.1 and Cloud Connected.
5. Submit a test exam with at least one auto-marked answer and one manual/drawing answer.
6. Confirm the result shows the full-paper total, auto-marked marks, pending teacher marks, time, questions answered, and result code.
7. Use Check Reviewed Work before and after teacher marking.

DATABASE
No SQL migration is required when upgrading from V3.2D.
Do not rerun the fresh schema or migration 08 on an existing V3.2D database.

NEW PROJECT
Run database scripts 01 through 08 in numeric order, then configure config.js.
