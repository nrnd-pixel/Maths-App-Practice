# Maths Practice V3.2F.2.1 — Open-Access Assignments

V3.2F.2.1 keeps the class and participation tools from V3.2F.2 while ensuring every enabled past paper remains open to everyone.

## What changes

- A Student ID is optional in Exam Mode.
- A recognised active roster Student ID links the attempt to its class assignment and participation summary.
- Missing, unrecognised or independent Student IDs can still start the paper normally.
- Suggested start dates, target due dates and target attempt counts provide guidance only.
- Passing a target date or reaching a target attempt count never blocks a new attempt.
- Assignment tracking never changes the paper timer. Only Exam Settings controls the countdown and automatic submission.
- Pausing assignment tracking stops new attempts from being linked to that class, but the paper remains open.

## What remains unchanged

Practice Mode, Exam Settings paper availability, recoverable attempts, duplicate-attempt protection, result codes, answer-release rules and manual review continue to work as before.

Run `migrate-v3.2F.2-to-v3.2F.2.1-open-access.sql` before deploying the V3.2F.2.1 `index.html`.
