# Maths Practice V3.2G.1

V3.2G.1 adds a teacher-only Analytics foundation to the complete past-paper practice platform.

## Current capabilities

- Practice Mode with structured question types, hints, second attempts and immediate feedback.
- Full-paper Exam Mode with autosave, recovery, navigation, flags and optional countdown.
- Result codes, reviewed work and teacher marking for manual or drawing responses.
- Exam Settings for availability, duration and answer-release rules.
- Classes, roster import, open-access assignments and participation summaries.
- Teacher-selectable open, Student-ID-only or Student-ID-plus-PIN access for both modes.
- Analytics overview with participation, completion, Exam status, pending-review and final-score summaries.
- Period, class, year, activity and student filters with a filtered CSV export.

## Upgrade from V3.2F.3

1. Back up the current site and database.
2. Do not run SQL for V3.2G.1.
3. Preserve the working `config.js`.
4. Deploy the V3.2G.1 upgrade folder.
5. Hard-refresh and complete `DEPLOY-AND-TEST-V3.2G.1.md`.

Open access remains available. Teachers can change access at any time from **Teacher Dashboard → Student Access**.
