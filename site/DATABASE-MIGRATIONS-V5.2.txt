V5.2B — Teacher Topical Exercise Library & Management
----------------------------------------------------
No database migration required.

Purpose:
- groups existing staged topical_exercise rows by year level + source/set name in a teacher-only library;
- reports set-level physical/logical question counts, marks, images, review state and structural attention indicators;
- reuses the established Question Bank selection, QA and review controls for question-level management;
- permits only a guarded set rename by updating the existing source field for every row in that inactive topical set;
- blocks set rename if any row is active or if the new name collides with another topical set in the same year level;
- does not create, activate, publish or expose topical questions to students.

V5.2B safety boundary:
- no schema changes;
- no student retrieval changes;
- no Practice grading/result changes;
- no Exam changes;
- no active-status changes;
- no deletion/archive action;
- topical student exposure remains OFF.

V5.2C — Student Topical Practice Library
----------------------------------------
20260830094514 v52c_student_topical_practice_library

Purpose:
- adds server-only public.topical_exercise_settings for set-level publication state; direct browser-role table access is revoked and RLS remains enabled with no direct policies;
- adds topical_source to student_access_tickets so a verified Practice ticket can be bound to one published topical set;
- adds topical_source to practice_sessions so topical results can be identified without overloading exam metadata;
- adds a teacher-only readiness/publication RPC path that requires every topical row to remain inactive, contain no exam metadata, pass metadata/image/multipart/duplicate checks, and have review_status=reviewed before publication;
- adds a public metadata RPC that lists only settings that are both published and still live-ready;
- adds dedicated bearer-token RPCs for binding access, retrieving reviewed inactive topical rows, grading topical responses, and submitting topical Practice sessions;
- leaves get_student_questions, grade_practice_response_v3 and submit_practice_session_v3 unchanged, so ordinary Practice continues to use active questions only through its established path.

V5.2C security boundary:
- topical questions remain inactive even when a set is later published;
- student retrieval requires an unexpired Practice access token bound to one currently published/live-ready set;
- correct answers, hints and explanations are not returned by topical question retrieval;
- grading and final submission validate the bound ticket and exact topical set before using inactive reviewed rows;
- teacher publication RPCs are authenticated-only and internally require public.is_teacher();
- student RPCs are intentionally callable by anon/authenticated roles but require bearer access tokens except for the safe published-set metadata list;
- all new SECURITY DEFINER functions pin search_path='';
- the internal readiness helper has EXECUTE revoked from anon/authenticated roles;
- no question active status, Exam Setting, grading logic for ordinary Practice, or past-paper publication setting was changed.
