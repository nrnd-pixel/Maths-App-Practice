Maths Practice V4.0 requires no new SQL migration.

V4.0 is a student-platform and presentation release built on the existing secure production schema and RPC architecture.

Keep the current production database objects already installed for the V3.x platform, including:
- existing tables and relationships;
- Row Level Security policies;
- teacher authorization helpers;
- student access and temporary-ticket RPC flows;
- server-authoritative grading and answer-release functions;
- assignment, result, review, progress, motivation, message and recommendation RPCs.

V4.0 adds sign-in-once browser-session continuity and the Learning Hub experience in the client. The student PIN is not stored. Practice and Exam continue to use separate temporary access tickets.

Do not run a new Supabase query solely for the V4.0 release.
Do not remove or replace existing production security functions or policies.
Do not alter production config.js values as part of this release note.
