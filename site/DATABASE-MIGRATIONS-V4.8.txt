Maths Practice V4.8 — Database Migration Statement
================================================

V4.8 adds NO new database migration.

V4.8A, V4.8B and V4.8C reuse the existing Practice assignment schema and the existing target date fields (`opens_at` / `closes_at`). V4.8C updates only the existing `practice_assignments.closes_at` and `updated_at` fields through the teacher-authorized assignment update model already used by the app.

Production migration history was re-checked before the V4.8 Release Candidate. Current migration tail remains:

Release instruction:
- Do not run SQL solely for V4.8 deployment.
- Do not re-run the V4.3 migrations.
- Preserve the existing production Supabase configuration.
- V4.8 does not change grading, mastery/intervention thresholds, assignment access enforcement, authentication, answer release or AI security.
- Overdue target dates remain guidance only and do not lock Practice.
- V4.8B does not introduce a second student assignment-access path.
- V4.8C does not create a new assignment; it only revises or clears the existing target due date.
