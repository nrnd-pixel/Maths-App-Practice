Maths Practice V4.1 — NO SQL MIGRATION REQUIRED

V4.1 reuses the existing secure production database schema, RLS policies, helper functions and RPC architecture already used by V4.0 / the V3.x platform.

V4.1 adds client-side learning-flow improvements only:
- Actionable Focus Areas
- Practice Mistake Recovery
- secure rotation across existing temporary Practice tickets
- Mastery Progress presentation
- PIN Enter-key sign-in guard
- Home priority promotion of existing server-classified Focus Areas
- V4.1 release presentation and documentation

V4.1 does NOT require:
- a new table or column;
- a new Supabase RPC;
- a new RLS policy;
- a grading-function change;
- an answer-release change;
- an assignment-state change;
- an Exam Mode database change;
- an AI provider/security migration.

Security boundaries to preserve:
- student PIN is never stored;
- Practice and Exam use separate temporary access tickets;
- assessment/grading authority remains server-side;
- Home Focus Areas are derived only from the existing secure learning-dashboard payload;
- the existing Practice question-selection path is reused for Focus and recovery sets;
- Exam Mode and Exam Assignments remain AI-free;
- production config.js must not be replaced solely for V4.1.

Do not run a new Supabase SQL migration solely for the V4.1 release.
